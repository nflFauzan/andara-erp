### **6. Infrastruktur & Teknologi** 

Bagian ini menjelaskan infrastruktur dan layanan teknis yang dibutuhkan agar sistem dapat berjalan di lingkungan production. Penjelasan disampaikan dalam bahasa bisnis yang sederhana. 

#### **Production Server** 

Aplikasi dijalankan pada satu server (Cloud/VPS) dengan spesifikasi 2 vCPU, 4 GB RAM, dan 80 GB SSD/NVMe storage, berbasis Ubuntu LTS, menggunakan Docker agar aplikasi (Spring Boot) berjalan secara konsisten, dengan Nginx sebagai reverse proxy dan PostgreSQL sebagai database utama untuk seluruh data transaksi dan master data. 

#### **Domain & Jaringan** 

Sistem diakses melalui domain .com yang dikelola melalui Cloudflare, yang menyediakan DNS, proxy, dan SSL/TLS (akses HTTPS yang aman) pada tingkatan Free. 

#### **Penyimpanan File (File Storage)** 

Bukti pembayaran dan attachment transaksi disimpan pada Cloudflare R2 (object storage), terpisah dari database utama, agar database tetap ringan dan performanya terjaga. Layanan ini berada pada tingkatan Free tier pada baseline saat ini. 

#### **Backup & Recovery** 

Database PostgreSQL dibackup otomatis minimal 1 kali sehari, disimpan pada bucket R2 yang terpisah dari file transaksi. Retention baseline yang digunakan: 7 backup harian, 4 backup mingguan, dan 3 backup bulanan. Sebelum peluncuran production, dilakukan minimal satu kali pengujian pemulihan (restore test) untuk memastikan backup benar-benar dapat digunakan saat dibutuhkan. 

#### **Monitoring** 

Ketersediaan layanan dipantau melalui UptimeRobot, dan error aplikasi dipantau melalui Sentry — keduanya pada tingkatan Free Tier. 

#### **Kendali atas Akun Infrastruktur dan Data** 

Prinsip utama pada bagian ini adalah Client memiliki kendali atas akun infrastruktur dan data bisnisnya sendiri. Untuk kejelasan, kedua hal ini dibedakan sebagai berikut. 

A. Akun Infrastruktur — domain, Cloudflare, server/hosting, Cloudflare R2, dan akun layanan terkait lainnya sebaiknya berada di bawah kendali CV. ANDARA (sebagai pemegang akun), dengan akses teknis diberikan kepada Developer sesuai kebutuhan pengerjaan. 

B. Data Bisnis — database production, data transaksi, data customer, serta file/attachment transaksi merupakan data operasional milik CV. ANDARA. Production infrastructure tempat data ini berjalan berada di bawah kendali Client, sementara Developer memperoleh akses teknis sesuai kebutuhan pengerjaan — bukan kepemilikan atas data itu sendiri. 

Tujuan utama pengaturan ini adalah kontinuitas operasional (continuity) dan kemudahan handover di masa depan, termasuk kemampuan Client berpindah developer/vendor apabila diperlukan, tanpa bergantung pada satu pihak untuk mengakses data atau infrastrukturnya sendiri.
